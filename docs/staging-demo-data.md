# 预发演示账号与结算追回数据

在已经完成数据库迁移的预发环境执行：

```powershell
$env:STAGING_DEMO_PASSWORD = '<至少 12 位的预发演示密码>'
pnpm --filter @ai-auto/api seed:staging-demo
```

脚本拒绝在 `NODE_ENV=production` 下运行，且不删除财务账或审计记录。重复运行会重置三类演示账号的密码；如果上一笔案例已经被裁决，它会新增一笔案例，而不是回写历史记录。

| 身份 | 登录账号 | 登录入口 |
| --- | --- | --- |
| 运营管理员 | `staging_ops_admin` | `/auth/admin/login` |
| 商户 | `13900001001` | `/auth/merchant/login` |
| 创作者 | `18800001001` | `/auth/agent/login` |

每次准备完成后，运营后台会有一条“预发演示：商户申请撤销已结算报酬并验证后续自动追回”的待处理报酬申诉。关联报酬为 ¥168，状态为已结算，创作者钱包有同额可用余额。运营以管理员身份在该申诉上选择“撤销/追回结算”，并确认 ¥168，即可验证即时扣回；如需验证后续自动抵扣，先在预发库将该创作者的钱包可用余额模拟为已提现，再裁决，并产生新的已核验报酬。
