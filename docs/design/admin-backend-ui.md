## 1. 设计原则

- **数据密集**：运营后台需要高信息密度，支持大屏展示
- **告警突出**：风险事件用醒目的红色/橙色标出
- **操作安全**：高风险操作（封禁/拒绝）必须二次确认
- **专业克制**：纯数据导向，减少装饰性元素

### 色彩应用

```
页面背景：       Neutral-100 (#edf2f7)
侧边栏：        Neutral-900 (#1a202c) 深色
侧边栏文字：     Neutral-300 (#cbd5e0)
主色：          Primary-800 (#2c5282)
KPI正向：       Success-700 (#276749)
KPI负向/告警：  Danger-700 (#c53030)
待处理：        Warning-700 (#b7791f)
纯白卡片：       White (#ffffff)
表格标题：       Neutral-100 背景
```
