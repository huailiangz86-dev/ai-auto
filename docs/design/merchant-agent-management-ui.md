## 1. 设计原则

- **激励可视化**：分享员的等级、佣金贡献一目了然
- **招募便捷**：一键生成招募链接/二维码，可分享
- **管理轻量**：商家不需要频繁管理分享员，重点在看数据

## 组件清单

| 组件名                            | 规格                                |
| --------------------------------- | ----------------------------------- |
| AgentCard（分享员卡片）           | 等级徽章+KPI数据+操作按钮行         |
| LevelBadge（等级徽章）            | 5级5色，圆角方形                    |
| AgentDetailPanel（分享员详情）    | 绩效数据+客户列表+核销记录+招募漏斗 |
| CustomerTable（客户列表）         | 昵称+核销+佣金贡献，可导出          |
| RedemptioTable（核销记录）        | 时间+商家+券名+金额+佣金+状态       |
| FunnelChart（招募漏斗）           | 曝光→注册→绑定→活跃四层漏斗         |
| RecruitmentLink（招募链接卡片）   | 链接+二维码+分享按钮                |
| QrCode（二维码）                  | 256×256px，白底，支持下载/打印/分享 |
| RecruitmentTrend（招募趋势图）    | 柱状图，按日展示新增分享员数        |
| RecruitmentSource（招募来源饼图） | 环形图，链接扫码/二维码/短信占比    |
| ActivityChart（活跃度条）         | 填充百分比条形图                    |
