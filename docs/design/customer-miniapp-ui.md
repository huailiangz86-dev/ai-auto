## 1. 设计原则

### 微信小程序规范

- **微信绿为主色**：`#07c160`（微信官方绿）
- **微信原生组件**：优先使用微信原生组件（button, input, scroll-view）
- **视觉风格**：微信官方风格，蓝白配色，简洁清晰
- **字体**：系统字体（PingFang），不要自定义字体
- **安全区域**：适配 iPhone X 及以上（底部 Home Indicator）

### 色彩系统（小程序专用）

```
主色（微信绿）：  #07c160   /* 主要按钮/链接/Tab选中 */
主色深：          #059544   /* 按钮按下态 */
主色浅：          #E8F8EE   /* 成功背景/徽章 */
辅助蓝：          #576B95   /* 次要链接/文字 */
价格红：          #FA5151   /* 折扣金额高亮/原价删除线 */
价格橙：          #FF6B00   /* 待使用/限时标签 */
背景灰：          #F7F7F7   /* 页面背景 */
卡片白：          #FFFFFF   /* 卡片背景 */
文字主：          #333333   /* 标题/重要文字 */
文字副：          #666666   /* 正文 */
文字弱：          #999999   /* 辅助/占位 */
分割线：          #E5E5E5   /* 分割线 */
```

### 字号规范（微信小程序）

```
Title:    36rpx (18pt)  /* 页面标题 */
Headline: 32rpx (16pt)  /* 卡片标题 */
Body:     28rpx (14pt)  /* 正文 */
Caption:  24rpx (12pt)  /* 辅助/说明 */
Mini:     20rpx (10pt)  /* 徽章/标签 */
Price:    48rpx (24pt)  /* 券价值（突出显示）*/
```

### 安全区域适配

