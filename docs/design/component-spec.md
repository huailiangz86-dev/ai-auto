## 1. Button 按钮

### 1.1 变体（Variant）

| 变体            | Background  | Text        | Border      | Shadow | Use                 |
| --------------- | ----------- | ----------- | ----------- | ------ | ------------------- |
| Primary         | Primary-800 | White       | none        | none   | 主要操作            |
| Primary-Hover   | Primary-700 | White       | none        | none   | -                   |
| Primary-Pressed | Primary-900 | White       | none        | none   | -                   |
| Secondary       | Transparent | Primary-800 | Primary-200 | none   | 次要操作            |
| Secondary-Hover | Primary-50  | Primary-700 | Primary-300 | none   | -                   |
| Ghost           | Transparent | Neutral-700 | none        | none   | 文字按钮            |
| Ghost-Hover     | Neutral-100 | Neutral-900 | none        | none   | -                   |
| Danger          | Danger-700  | White       | none        | none   | 删除/封禁等危险操作 |
| Danger-Hover    | Danger-900  | White       | none        | none   | -                   |

### 1.2 尺寸

| 尺寸    | Height | Padding   | Font-Size | Radius | Icon-Size |
| ------- | ------ | --------- | --------- | ------ | --------- |
| Large   | 48px   | 16px 24px | 16px      | 8px    | 20px      |
| Default | 40px   | 8px 16px  | 14px      | 8px    | 16px      |
| Small   | 32px   | 4px 12px  | 12px      | 6px    | 14px      |
| Mobile  | 44px   | 10px 20px | 15px      | 8px    | 18px      |

### 1.3 状态

```
状态优先级（从高到低）：
1. Loading   — 显示 spinner，文字变淡，禁用交互
2. Disabled  — 透明度 50%，禁用交互
3. Hover     — 背景色变化，cursor: pointer
4. Active/Pressed — 背景色加深，scale(0.98)
5. Default   — 正常显示
```

### 1.4 图标按钮

```
图标按钮（无文字）：
┌───────┐
│  🔔  │  ← 40×40px，Radius-full
└───────┘

图标按钮（有文字）：
┌──────────────┐
│  📋  新建  │  ← 图标16px + 文字间距8px
└──────────────┘
```

### 1.5 按钮组

```
按钮组（横向）：
┌──────────┐  ┌──────────┐  ┌──────────┐
│  上一步  │  │  取消  │  │  下一步 →│
└──────────┘  └──────────┘  └──────────┘
间距：12px

按钮组（纵向）：
┌──────────┐
│  Primary │
└──────────┘  ← 间距 12px
┌──────────┐
│ Secondary │
└──────────┘
```

## 2. Input 输入框

### 2.1 状态

```
默认态：
┌─────────────────────────────────────┐
│  标签文字                           │  ← Text-sm, Neutral-600
│ ┌─────────────────────────────────┐│
│ │                                  │││  ← Text-md, Neutral-900
│ └─────────────────────────────────┘│
│  提示文字                           │  ← Text-xs, Neutral-500
└─────────────────────────────────────┘
Border: Neutral-300 (1px)
Background: White
Radius: 8px
Height: 40px

聚焦态（Focus）：
Border: Primary-500 (2px)
Shadow: 0 0 0 3px Primary-100
（注意：聚焦时 border 变粗 1px→2px，需要调整 padding）

错误态（Error）：
Border: Danger-500 (1px)
Background: Danger-50
Label 颜色: Danger-700
错误提示: ┌─────────────────────────────────┐
         │ ⚠️ 请输入正确的手机号            │  ← Text-xs, Danger-700
         └─────────────────────────────────┘

禁用态（Disabled）：
Border: Neutral-200
Background: Neutral-100
Text: Neutral-500
Cursor: not-allowed
```

### 2.2 变体

| 变体          | 区别                            |
| ------------- | ------------------------------- |
| TextInput     | 标准文本输入                    |
| TextArea      | 多行文本，高度自适应，最小 80px |
| PasswordInput | 密码输入，显示/隐藏切换         |
| NumberInput   | 数字输入，右对齐，支持 +/- 按钮 |
| PhoneInput    | 手机号输入，+86前缀固定         |
| SMSInput      | 验证码输入，右侧验证码按钮      |
| SearchInput   | 搜索框，左侧放大镜图标          |
| DateInput     | 日期选择，右侧日历图标          |
| FileInput     | 文件上传，拖拽区域 + 点击上传   |

### 2.3 SearchInput 规范

```
┌─────────────────────────────────────────────┐
│  🔍  搜索商家名称、券名...                  │
└─────────────────────────────────────────────┘
前缀图标：16px，Neutral-500
Placeholder：Neutral-500
清空按钮：输入后右侧显示 X
搜索触发：回车 或 延迟 300ms 自动搜索
```

### 2.4 带图标的 Input

```
左侧图标：
┌─────────────────────────────────────────────┐
│  📱  │                                  │
└─────────────────────────────────────────────┘
左侧图标宽度：40px

右侧图标/按钮：
┌─────────────────────────────────────────────┐
│                              │  👁  或  ⟩ │
└─────────────────────────────────────────────┘
右侧图标宽度：40px
```

## 4. Table 表格

### 4.1 基础规范

```
┌─────────────────────────────────────────────────────────────────┐
│  列A  │  列B（可排）↕  │  列C（可排）↕  │  操作        │  ← 表头
├─────────────────────────────────────────────────────────────────┤
│  数据1 │  数据2         │  数据3         │  [查看] [编辑]│  ← 奇数行
├─────────────────────────────────────────────────────────────────┤
│  数据4 │  数据5         │  数据6         │  [查看] [编辑]│  ← 偶数行（斑马纹 Neutral-50）
├─────────────────────────────────────────────────────────────────┤
│  数据7 │  数据8         │  数据9         │  [查看] [编辑]│  ← 奇数行
└─────────────────────────────────────────────────────────────────┘
```

**表头样式：**

- Background: Neutral-100
- Text: Text-sm, Font-weight 600, Neutral-700
- Height: 44px
- Padding: 12px 16px
- 可排序列：右侧 ↑↓ 图标

**数据行样式：**

- Height: 48px（最小）
- Padding: 12px 16px
- Text: Text-md, Neutral-900
- Hover: Primary-50 背景
- 斑马纹：奇数行 White，偶数行 Neutral-50

**操作列：**

- Width: 固定，最小 120px
- 按钮：Ghost，无边框
- 操作按钮过多时：显示前2个 + "更多 ⟩"

### 4.2 排序规范

```
无排序：
┌──────────────┐
│  列名        │  ← 无图标
└──────────────┘

升序：
┌──────────────┐
│  列名  ↑    │  ← Primary-700 颜色
└──────────────┘

降序：
┌──────────────┐
│  列名  ↓    │
└──────────────┘
```

### 4.3 分页

```
┌─────────────────────────────────────────────────────────────────┐
│  共 234 条记录                        每页 20条  ▼    1 2 3 ... │
│                                                          11 ⟩ │
└─────────────────────────────────────────────────────────────────┘
每页条数选择：20 / 50 / 100
分页按钮：首页 / 上一页 / 数字 / 下一页 / 末页
当前页：Primary-800 背景，White 文字
```

### 4.4 固定列

```
左固定列（操作列）：
┌───────┬─────────────────────────────────────────────────────────────────┐
│ 操作  │  列A  │  列B  │  列C  │  列D  │  列E  │  列F  │
├───────┼─────────────────────────────────────────────────────────────────┤
│ 查看  │ 数据1  │ 数据2  │ 数据3  │ 数据4  │ 数据5  │ 数据6  │  ← 左固定列有白色背景
│ 编辑  │ 数据1  │ 数据2  │ 数据3  │ 数据4  │ 数据5  │ 数据6  │     Shadow-sm
│ 删除  │ 数据1  │ 数据2  │ 数据3  │ 数据4  │ 数据5  │ 数据6  │
└───────┴─────────────────────────────────────────────────────────────────┘
     ↑ 固定宽度 120px，右侧 Box-shadow
```

## 5. Modal 弹窗

### 5.1 尺寸

| 尺寸       | Width            | Use               |
| ---------- | ---------------- | ----------------- |
| Small      | 400px            | 确认对话框        |
| Medium     | 560px            | 表单弹窗          |
| Large      | 720px            | 详情/编辑         |
| Full-Width | 90vw, max 1200px | 复杂表单/数据展示 |

### 5.2 结构

```
┌─────────────────────────────────────────────────────────────┐
│  标题文字                              [X]              │  ← Header
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  内容区域                                                  │
│  （可滚动）                                               │
│                                                             │
│                                                             │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│          [取消]                    [确认]                 │  ← Footer
└─────────────────────────────────────────────────────────────┘

Header:
- Height: 56px
- Border-bottom: Neutral-200
- Title: Text-lg, Font-weight 600
- Close button: 右侧 16px

Content:
- Padding: 24px
- Max-height: calc(100vh - 200px)，超出可滚动
- 禁止在此区域外出现滚动条

Footer:
- Height: 64px
- Border-top: Neutral-200
- 按钮组：右对齐，间距 12px
```

### 5.3 蒙层

```
Overlay（遮罩层）：
Background: rgba(0, 0, 0, 0.45)
动画：fadeIn 250ms ease-out
点击蒙层：关闭弹窗（除非禁止关闭）

禁止关闭（danger action）：
Header 的 [X] 按钮 + 蒙层点击 均禁用
Footer 取消按钮必须存在
```

### 5.4 确认对话框（Confirm）

```
┌─────────────────────────────────────┐
│  ⚠️                               │  ← 警告图标 32px
│                                     │
│  确认删除这个活动？                   │
│                                     │
│  此操作不可撤销，相关数据将永久删除。  │  ← Text-sm, Neutral-600
│                                     │
│  ┌───────────┐  ┌───────────────┐ │
│  │   取消    │  │   确认删除    │ │  ← 确认按钮 Danger
│  └───────────┘  └───────────────┘ │
└─────────────────────────────────────┘
Width: 400px
警告图标颜色：Warning-500
确认按钮：Danger 变体
```

```

```

```
- 使用 monospace 字体
- 千分位分隔符
- 整数部分逗号分隔
```

### 10.2 必填标记


### 10.3 表单校验规则

```
触发时机：
- Input blur 时触发当前字段校验
- Form submit 时触发全表单校验
- 实时校验（可选）：Input change 时实时校验

错误提示：
- 显示在输入框下方
- 红色文字 + ⚠️ 图标
- 1-2 行，超出换行
- 动画：从透明渐变为可见

错误输入框：
- Border 变红
- 背景变浅红
```
