## 1. 设计原则

- **零门槛创作**：用户可能没有文案经验，AI 引导要温和自然
- **变现激励**：每次创作都链接到赚钱机会（分享→领佣金），强化动机
- **微信风格**：保持微信小程序规范，操作轻量
- **安全感**：明确告知 Token 费用（从优惠券/奖励扣除），透明不套路
