## 1. 设计原则

- **引导式创建**：4步向导 + AI 对话式两种模式并行，商家自由选择
- **券价值突出**：券面值要醒目，让商家快速理解
- **预算可视化**：佣金支出、剩余预算一目了然
- **操作低门槛**：每个页面只做一件事，减少认知负担
