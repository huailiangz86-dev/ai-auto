## 1. 设计原则

- **专业感 > 花哨**：佣金数据要让人信任，钱的事情不能像玩具
- **低门槛操作**：商家多为中小老板，减少表单字段，每步只做一件事
- **信息分层**：关键数据突出，次要数据可展开
- **颜色语义化**：绿色=入账/成功，橙色=待处理/警告，红色=拒绝/风险

**字段说明：**

| 字段       | 类型       | 校验规则            | 说明                            |
| ---------- | ---------- | ------------------- | ------------------------------- |
| 商户名称   | TextInput  | 2-50字，必填        | 即店铺名，建议格式：品牌名+地名 |

- 验证码发送失败时显示具体错误（频繁/格式错误）
- 下一步按钮：所有必填字段通过后变为 Primary 蓝色

### 3.2 KPI 卡片详细规范

**卡片尺寸：** 宽度自适应网格，高度 100px
**KPI 卡片数据格式：**

```
┌────────────────────────────────┐
│  ¥3,420.00            [¥↑]   │  ← 金额（居左）+ 趋势箭头（居右）
│  今日核销                    │  ← 指标名称
│  ━━━━━━━━━━━━━━━            │
│  昨日 ¥2,894                │  ← 对比基准（灰色小字）
│  +18.2%                    │  ← 环比变化（绿色=上升，红色=下降）
└────────────────────────────────┘
```

**金额颜色规范：**

- 正向指标（核销额/新增客户）：绿色数字
- 负向指标（退款/投诉）：红色数字
- 中性指标（领取数/浏览量）：黑色数字

**趋势箭头：**

- 上升：绿色 ↑
- 下降：绿色 ↓（核销/领取/客户相关为正向）
- 下降：红色 ↓（仅在下降为负向时）

### 3.3 核销趋势图规范

**图表类型：** 柱状图（核销额）+ 折线图（核销率）
**X轴：** 日期
**Y轴：**

- 左侧：核销金额（¥）
- 右侧：核销率（%）
