## 1. 设计原则

- **佣金感知**：金额数字要大、要醒目，激励感强于信息密度
- **即时反馈**：每次核销/提现有明确的状态和通知
- **移动优先**：单手操作，拇指区为主要交互区
- **收益感强**：用金色/绿色强调可提现金额，给分享员信心

### 色彩应用

```
首页顶部背景：Primary-800（深蓝，专业感）
可提现金额：  Commission-Gold (#d69e2e)，大字体
待结算金额：  Commission-Orange (#dd6b20)
已到账金额：  Success-700 (#276749)
等级进度条：  Primary-500 (#63b3ed)
危险/失败：    Danger-700 (#c53030)
```
