## 1. 设计原则

- **生成即分发**：AI生成 → 一键分发到多平台，路径最短
- **平台差异化**：不同平台的文案语气/格式不同，AI自动适配
- **Token 透明**：生成前明确展示费用，消除分享员顾虑
- **进度可见**：生成和发布过程全程可见，消除焦虑

### 色彩应用（移动端）

```
主色：Primary-800 (#2c5282) — 按钮/导航
AI生成区：Primary-50 (#f0f9ff) — 背景区分
Token费用：Neutral-600 (#4a5568) — 费用数字
成功：Success-700 (#276749) — 发布成功
进行中：Primary-500 (#63b3ed) — 进度条
平台色：各自品牌色（抖音黑/小红书红/微信绿）
```
