# AI auto 发布助手（测试版）

这是一个 Chrome / Edge Manifest V3 浏览器扩展。它接收 AI auto 分享员工作台中已确认的文案，打开对应平台的发布页，并在页面内提供“复制文案”与“尝试预填”。

它**不会**调用平台发布 API、保存平台登录态或模拟点击平台的“发布”按钮。最终发布、验证码和风控处理都由登录该平台的用户自行完成。

## 本地安装

1. 打开 Chrome 或 Edge 的扩展管理页面，并开启“开发者模式”。
2. 选择“加载已解压的扩展程序”。
3. 选择本目录：`apps/publish-assistant-extension`。
4. 打开分享员工作台（开发环境为 `http://localhost:3102`），在“AI 创作与分发”中选择一条已确认文案，点击“发送到发布页”。

## 测试边界

- 首期接入抖音、小红书、视频号和快手的发布入口；具体页面结构由各平台控制，输入框定位失败时仍可一键复制粘贴。
- 文案只存入浏览器的临时会话存储，打开页面时取用一次，或十分钟后过期；不会写入平台页面 URL、服务器或浏览器持久存储。
- 因各平台页面可能变化，预填属于辅助能力。界面会明确提示用户检查内容并手动发布。
